# Glossary

Every ML Systems term in one place. Terms link to their full treatment where one exists.

| Term | Meaning |
|---|---|
| **Value Chain** | The spine: [Loan Origination → Deconstruction → Construction](value-chain.md), closed into an equity loop by the homeowner's choice to keep building. |
| **Loan Pit** | The reverse-auction marketplace (Node 1) where lenders compete to fund the homeowner. Run by the mind PIT LORD. |
| **Equity loop** | Each decon+rebuild cycle creates physical equity, qualifying the homeowner for the next cycle. Client-driven, not assumed. |
| **Master Ledger** | The [single, auditable record of claims](master-ledger.md) about one home, with many authors and content-bound verification. |
| **Claim** | A statement about a house from some party (homeowner, assessor, a mind), carrying source + evidence grade + verification state. |
| **Domain-scoped authority** | Reconciliation rule: authority is scoped per domain, not flat, so the right source wins per kind of fact. |
| **Reconciliation state** | An entry's resolution: confirmed / reconciled / single-source / conflict / unverified. |
| **Two-key verification** | Ledger entries stamped by both homeowner and Custodian. |
| **Lapsing signature** | A `VER:` stamp bound to a content hash — editing the content voids the stamp. |
| **Collective Ontology** | The [shared grammar](collective-ontology.md) that lets every mind describe the same house without collision. |
| **HomeGenome** | The compact, canonical DNA of one home — the output of [ontological compression](ontological-compression.md). |
| **Ontological Compression** | Reducing everything known about a home into a HomeGenome; signal over redundancy. |
| **Ontology codes** | Stable `SECTION:task` tags for claims/outputs in seven families — `FIN` `DEC` `DES` `BLD` `MKT` `VER` `LUP`. Extend codes, not storage. See [The Seven Families](the-seven-families.md). |
| **Envelope** | The building shell that absorbs individual wall/opening claims into one record. |
| **Assembly stack** | Foundation → floors → walls → roof, each with a takeoff. |
| **The Seven Minds** | [PI, MIA, VERA, REAPER, PIT LORD, CDA, MURPHY](the-seven-minds.md) — the AI agents, with the Custodian as a human peer. |
| **Custodian** | The founder, rendered as a peer mind: fiduciary + operational governance, verification, oversight. |
| **PI** | Orchestrator · project intelligence — the sole homeowner-facing mind. |
| **MIA** | Market intelligence · signals — the market consciousness. |
| **VERA** | Verification · quality firewall — assessor harvest + facade/sketch/roof vision + deep search. |
| **REAPER** | Deconstruction · material recovery — tonnage, BOM, RRR, recovery report. |
| **PIT LORD** | Reverse-auction loans · RCM — runs the Loan Pit. |
| **CDA** | Design plan-stack swarm — plan gaps, massing, blueprint readiness, takeoffs. |
| **MURPHY** | Construction execution — milestones, schedule, per-phase pricing. |
| **RRR** | Reuse › Resale › Recycle — route each recovered material to its most valuable recoverable state. |
| **RCM** | Reversed Conventional Mortgage — a **parked** earlier product; 100% of payment to principal, interest deferred. Not current value-chain logic. |
| **ML1 / ML2 / ML3** | Physical neural net: Manual Labor → Measured Learning → Machine Learning. |
| **LM / FA / AE** | Financial neural net: Language Modeler / Financial Architect / Accounting Engineer. |
| **EV / CR / GW** | Dance neural net: Events-Sponsors / Creativity / Generational Wealth. |
| **TT · LL · MVE lens** | The Custodian's build-logic overlook: grounded-share (TT) · Lucent Lens (LL) · minimum-viable-estimate (MVE). |
| **MEASURED / MODELED / ASPIRATIONAL** | [Reality labels](../README.md#reality-labels): exists today / calibrated projection / a goal not encoded. |
| **CONSTRUCTION_VALUE_MULTIPLIER** | 1.43× per cycle (MODELED) — physical value creation, not market appreciation. |
| **VGSI** | Vision Government Solutions — the town/assessor record source VERA harvests. |
| **WCS / WSDC** | West Coast Swing / World Swing Dance Council — the community engine of the dance net. |
