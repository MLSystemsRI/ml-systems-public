# The Stage We're At

*Last updated: September 2026.*

ML Systems is a **bootstrapped, pre-revenue construction company with a shipped software
platform**. This page is deliberately honest about what exists today versus what is modeled or
aspirational — the same [reality labels](../README.md#reality-labels) used everywhere in this repo.

---

## ✅ Shipped and live (MEASURED)

- **Mobile app approved on both stores.** iOS (App Store) and Android (Google Play) are
  approved and live. Bundle id `com.mlsystems.app`.
- **Web guest preview** at `try.mlsystemsri.com` — the app running as a no-login guest.
- **The Seven Minds** are wired into a single collective chat + cockpit, orchestrated by PI.
- **The Master Ledger** is real: record-first UI, two-key verification, lapsing signatures
  bound to content hashes, and a Custodian oversight console that derives a review queue across
  every home.
- **Ontological compression** runs on-device at intake: a home is compressed into a HomeGenome +
  ontology row, persisted per property/cycle.
- **VERA's intelligence stack** is live against free public data: assessor (VGSI) harvest,
  facade vision from StreetView / satellite / homeowner photos, sketch reconciliation, and deep
  search (FEMA flood zones, Census tracts, RIGIS). Google (Solar / Elevation / StreetView) tiers
  unlock with a Maps Platform key.
- **The Loan Pit** exists in-app: live-bid loan cards, a real partner-lender directory, and
  financing lanes (bridge / conventional / the parked RCM).
- **Marketing + onboarding web** across the `.com` and a unified `.net` onboarding portal for six
  party types (contractor, loan officer, engineer, architect, homeowner, supplier).
- **Business identity:** ML Systems LLC (structured internally as a C-Corp), D-U-N-S registered.

## 📐 Modeled — real math, not yet field-proven (MODELED)

- **80–90% material recovery** rate (target).
- **CONSTRUCTION_VALUE_MULTIPLIER = 1.43× per cycle** — calibrated from a competitor proforma +
  the ML Systems construction model. See [Ontological Compression](ontological-compression.md).
- **The Loan Pit economics** and reverse-auction mechanics.
- **Unit economics** — sourced from a real local-competitor proforma (269 work days, RI job
  sites): ~16% gross margin baseline, with a modeled path to ~23% via origination + recovery.

## 🎯 Aspirational — goals, not encoded in system logic (ASPIRATIONAL)

- **The 2-day crane deconstruction sequence** — no ML Systems deconstruction has been performed
  yet.
- **Humanoid-robot Tier-1/Tier-2 labor** — the endgame the [physical neural net](neural-net-architecture.md)
  is built toward; not modeled in any financial scenario.
- **Growth targets** (1 home/year launch → 20 homes/year by 2030 → ~$500M portfolio by 2035) —
  projections; nothing in the engine depends on them.

   property as homeowner #1 — the cleanest possible first move.
2. **Regulatory compliance** for the lending side — licensing and disclosure gate what the Loan

   highest-value product (robotics training data). See [Collective Ontology](collective-ontology.md).

## The honest summary

The **software is real and shipped**. The **construction loop is modeled and about to be run
for the first time**. The **robotics endgame is aspirational** and deliberately kept out of the
numbers. That gap — between a working platform and an unproven physical loop — is exactly where
ML Systems is right now, and the reality labels exist so nobody has to guess which is which.
