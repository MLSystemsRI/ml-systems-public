# ontology/

**The Collective Ontology as a designed thing — seven families, every slot, and the diagram.**

This folder is the public tranche of the ontology work. It is generated from a private working
copy, so the data here and the docs that cite it cannot drift apart.

| File | What it is |
|---|---|
| [`families.json`](families.json) | The seven code families with every slot — **shipped** (in the engine today) and **proposed** (design, not yet code) — plus domains, claimants and topology. **Generated; do not hand-edit.** |
| [`master-ledger-workflow.html`](master-ledger-workflow.html) | Self-contained page: the three-column workflow — seats on the left, the Master Ledger in the middle, claimants without seats on the right — with every family browsable beneath it. Open it locally; no build, no network beyond a font. |
| [`source-brief.md`](source-brief.md) | The writing brief for posts on this subject — what may be stated as measured, what must be called proposed, canonical wording, what stays out. |
| [`articles/`](articles/) | Post drafts. First: [Seven Families, One Ledger](articles/seven-families-one-ledger.md). |

Start with [`../docs/the-seven-families.md`](../docs/the-seven-families.md) for the narrative, then
open the HTML.

> No ML Systems deconstruction has been performed yet. Slots marked **proposed** are design;
> anything that depends on a job having run is aspirational.
